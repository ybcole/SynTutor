# SynTutor Evaluation Questionnaire

Companion instrument set for the SynTutor evaluation study.

**Respondents**
- **Group 1 — Students:** 50 BSCS students (usability + learning gain).
- **Group 2 — Experts:** 3 English/Linguistics faculty (parsing accuracy + XAI correctness).

**Administration:** Phase 1 = pretest, Phase 2 = system interaction, Phase 3 = posttest + SUS, Phase 4 = expert validation of benchmark outputs.
