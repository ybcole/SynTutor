# ADR 0002: Source-backed schema extension and M4 entry

Status: Accepted under the project owner's standing approval and request to fix blockers.
Date: 8 November 2026 (Asia/Manila).

The supplied B-R third-edition source pages establish zero-word DET/C1 and E positions and unlabelled wh triangles under C2. Canonical 1.1.0 represents them explicitly; it does not relabel them as gaps or fabricate lexical terminals. The schema and Python checks retain 1.0.0 compatibility for its original subset. Existing source anomalies remain flagged. Builder rejects structures its current bridge cannot preserve before clearing the workspace; full editor support belongs to M6.

M4 entry requires source-grounded instructional prerequisites from both authorities. The production registry now has independently checked structural and grammatical teaching starters with exact edition/page provenance. An active grammaticality constraint is not a roadmap prerequisite for lesson authoring: M2 explicitly allows unsupported analyses to remain unresolved and M3 withholds claims without reviewed evidence. Report instructional readiness and runtime constraint coverage separately. Do not enable an unused or unreviewed constraint merely to make a readiness check pass. Every additional lesson/template still needs its applicable source review.

This interprets existing acceptance scope rather than changing it. The current acceptance report maps each criterion and records the intentionally unresolved cases, remaining corpus review, raw diagnostic canvas and M6 boundary. Existing progress/database data is not migrated. Revert this change to roll back the extension; retain fail-closed runtime registries.
