# SynTutor Phase 3 benchmark reliability review

**2026-11-22, Manila time.** The unchanged Phase 2 scorers reproduced all four reported baseline scores. The measured changes are fewer unnecessary W&I edits, one newly grounded EXPECT evidence word, and one newly aligned Burton–Roberts tree. BLiMP decisions and all previously aligned textbook trees were unchanged. The same samples informed this investigation and are development diagnostics. [Phase 2 report](SYNTUTOR_CODEX_SYSTEM_WIDE_RELIABILITY_REMEDIATION.md)

[BEA shared task](https://aclanthology.org/W19-4406/), [ERRANT](https://github.com/chrisjbryant/errant)

EXPECT's source/target evidence indices define the reference annotation. The unchanged scorer projects to source-only evidence, first requires a target overlap and then scores related tokens. Automatically adding those words merely to match the annotation would overstate the implemented explanation. [EXPECT paper](https://aclanthology.org/2023.acl-long.413/)

## Defect ledger

| Defect and impact | Reproduction and confirmed cause | Focused fix and controls | Remaining risk |
| --- | --- | --- | --- |
| P3-01, high, misleading auxiliary diagnosis and changed meaning | W&I `C.dev:774` changed the adjunct `leading` to `lead` because matrix verb lookup scanned any sibling's first leaf, including a detached clause, and classified lexical `doing` as auxiliary `do`. | The matrix checks the following verbal head of the same VP through adverbial modifiers, and lexical `doing/done` skip auxiliary `do` selection. API tests include lexical `do`, a modal with a parenthetical, a detached participial clause and a wrong modal complement. | Irregular or malformed candidate trees can still prevent confident complement identification. |
| P3-02, high, wrong voice advice and missing evidence | EXPECT 609 has reciprocal parser views of the same malformed `is … know` relation. The matrix prescribed progressive `knowing`; XAI accepted only the normal auxiliary dependency direction. Separately, spaCy labeled both a plausible passive and `The child is play outside` as `auxpass`. | Require corroboration for a plain verb and link it to its governing `be` even in the reverse `acomp` parse. Preserve uncertainty between active progressive and passive; require an attached agent `by` before a deterministic passive repair on this new path. Tests check exact target and evidence tokens, clause uncertainty, passive and progressive controls, a true passive repair and a pseudo-cleft. | An agentless passive can remain diagnosable but unrepaired. Bare forms misclassified as nouns are outside this fix. |
| P3-03, high, false agreement and witness drop | W&I `B.dev:1014` had a valid plural pivot. The existential rule read the first noun `plenty` as the number controller and published no participant spans. | Use the dependency-linked complement of `plenty of`, `lots of` and `a lot of` as the number witness where the parse corroborates it. Keep the agreement target on the verb and cite the pivot evidence. API controls cover plural, mass, past, an ordinary container noun and context-dependent ellipsis. | Colloquial singular agreement and coordinated or ambiguously attached pivots need register-sensitive review. [Cambridge quantity expressions](https://dictionary.cambridge.org/grammar/british-grammar/lots-a-lot-plenty), [Cambridge plenty](https://dictionary.cambridge.org/us/grammar/british-grammar/plenty) |
| P3-04, high, unnecessary article and meaning-changing quantity substitution | `B.dev:27` changed `summer` and adjective `little`. `A.dev:173` and two handball rows received unnecessary articles. The noun check assumed bare singular count readings and the quantifier check assumed every `little` marked amount. | Preserve established bare season, sport and activity readings. Give `little` its adjectival reading where the analysis supports it. Regressions protect size and mass interpretations, count alternatives and a genuine mass/count mismatch. | Bare readings can depend on wider context. The system does not infer intended lexical sense from dictionary absence. [Cambridge little and few](https://dictionary.cambridge.org/us/grammar/british-grammar/little-a-little), [Oxford handball](https://www.oxfordlearnersdictionaries.com/us/definition/english/handball), [Oxford summer](https://www.oxfordlearnersdictionaries.com/definition/english/summer_1) |
| P3-05, medium, canonical coverage loss | `ch9-d1bi` has an overt direct object before a stranded `to`. Gap detection found the PP, but projection expected it to be the first dependent. | In the existing FINAL-D1 mapper, recognize a bounded transfer-verb frame with an overt object and one stranded recipient PP. Retain the ditransitive verb label, object NP, `P` and coindexed NP gap. API controls use novel verbs and NPs. Chromium selects the actual preposition and checks the rendered explanation. | Multiple possible gaps, ambiguous frame selection and other prepositions remain guarded by the existing projection behavior. [Chapter 9 figure](../../web/content/book/ch09.trees.json) |
