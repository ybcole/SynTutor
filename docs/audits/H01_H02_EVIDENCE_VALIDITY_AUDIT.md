# SynTutor H01 and H02 evidence validity audit

Independent audit of existing technical evidence for *SynTutor: An Explainable AI-Based Framework for Syntax Tree-Driven Grammar Analysis and Learning Using NLP*. 22 November 2026, Manila time.

## Decision

**H01 — INSUFFICIENT EVIDENCE.** The saved records support reproducible, descriptive tree agreement and coverage scores. They do not establish high constituency accuracy across prespecified complexity levels on unfamiliar inputs. The present FINAL-D1 result is **68.46% full labeled span F1 on 186 of 216 textbook inputs**, with **32/216 full exposed-span exact matches**. The strongest claim is agreement with a development-exposed reference set under a specified scorer.

**H02 — INSUFFICIENT EVIDENCE.** No located comparison holds inputs constant and independently measures incorrect feedback from a grounded system and a comparable baseline. Rule-backed explanations, correctly referenced evidence, and agreement between API views establish implementation properties. The causal claim and the rate of linguistically wrong feedback are unmeasured. Neither null hypothesis has a defensible statistical decision.

**VERIFIED** denotes a reproduced calculation, an observed artifact, or a bounded technical check. **QUESTIONABLE** denotes a mismatched record, an ambiguous reference, or a conclusion that overreaches its measure. **INSUFFICIENT EVIDENCE** denotes an outcome for which the necessary reference, comparison, or observations were unavailable. These judgments apply to H01 and H02 and their technical objectives.

## 2. H01 syntax-tree correctness

### Recalculation and coverage

On aligned canonical outputs, span precision is matched labeled spans divided by predicted spans, recall is matches divided by reference spans, and micro F1 is twice the matches divided by the total of predicted and reference spans. Unlabeled scoring drops the category. Both variants compare span multisets. The reported exact metric tests equality of these exposed labeled span multisets, with punctuation, empty elements, and designated direct preterminals excluded. Equality does not certify all node roles, gap indices, internal features, or alternative readings. The triangle-aware variant waives strictly contained predicted spans inside collapsed reference yields, so its denominator and interpretation differ from full scoring. [Scoring implementation](technical_evaluation/run_technical_evaluation.py), [FINAL-D1 evaluation path](technical_evaluation/run_real_world_reliability.py), [original PARSEVAL work](https://aclanthology.org/H91-1060/)

| --- | ---: | ---: | ---: | ---: | ---: |
| Pinned Chapter 5 archive | 103/216, 94/216 | 609 / 1,006 / 569 | 70.46% / 72.20% | 6/94 / 6/216 | 90.10%, 59/94 / 59/216 |
| Phase 3 start | 200/216, 185/216 | 1,006 / 1,614 / 895 | 68.32% / 72.44% | 32/185 / 32/216 | 84.20%, 100/185 / 100/216 |

## 3. H02 grammar, corrections, and explanation evidence

### Verdicts and rule application

Recomputed with ungrammatical as the positive class. Strict rule scoring treats unverified as no positive detection. Decisive hybrid scoring removes unverified rows. Hybrid flagging instead counts unverified as flags, which can be useful for triage. These policies answer different questions. For each strict row, accuracy is `(TP+TN)/N` and F1 is `2TP/(2TP+FP+FN)`.

| BLiMP strict rule records | TP / TN / FP / FN | Accuracy | F1 | MCC | Unverified |
| --- | ---: | ---: | ---: | ---: | ---: |
| Pinned Chapter 5 sample A, 240 | 49 / 100 / 20 / 71 | 62.08% | 0.5185 | 0.2670 | 22 |
| Pinned Chapter 5 sample B, 240 | 56 / 100 / 20 / 64 | 65.00% | 0.5714 | 0.3225 | 16 |
| Checked-in historical prediction CSV, 240 | 52 / 116 / 4 / 68 | 70.00% | 0.5909 | 0.4729 | 7 |
| Phase 3 final, 116 in 58 pairs | 42 / 50 / 8 / 16 | 79.31% | 0.7778 | 0.5919 | 2 |

**VERIFIED.** In archived sample B, hybrid flagging produces F1 0.8506 with 30 false flags, compared with 20 strict-rule false positives. In the current 116 items, hybrid decisive F1 is 0.8485 at 100/116 coverage. Of the strict-rule 92 nominally correct binary decisions, two are grammatical controls where the rule channel abstained, so exact three-status agreement is 90/116. Both members have exactly correct rule verdicts in 33/58 pairs. Sentence and pair agreement do not verify which rule fired or which text span caused the error. The evidence contains no independent rate of correct Cambridge rule application across the evaluated sentences. The differences between samples, configurations, and policies preclude interpreting the table as a trend or a test of H02. BLiMP uses expert-designed contrast types, generated minimal pairs and human validation of a sample. Its labels represent acceptability contrasts and do not provide validated explanations for every item. [BLiMP paper](https://aclanthology.org/2020.tacl-1.25/), [current historical CSV](technical_evaluation/RAW_PREDICTIONS.csv)

**VERIFIED as a regression-audit observation.** A fresh offline run of the existing `scripts/audit_rules.py` exited 1. It found five verdict mismatches on 335 development cases and 51 unlisted edges across 26 distinct types among 3,342 evaluated edges. The five expected violations were a bare singular subject, `some` under negation, a fused sentence, an introductory comma and a stative progressive. Some of these categories have context or register exceptions, and the script does not independently adjudicate its answer key. Its printed 113/112 coverage mixes observed IDs with registered IDs. With one of the 112 registered IDs unused, the registered intersection is 111/112. The zero-regression, zero-unrated criterion is unmet in this run even on its own terms. **INSUFFICIENT EVIDENCE.** Archived rules-only versus hybrid is a decision-policy comparison on a shared grounded pipeline. ## 6. Minimum additional evidence

1. **H01: one frozen reference cohort for the claimed output.** Define the evaluated layer, target population, numerical success threshold or comparator, and complexity categories before viewing predictions. If testing Benepar, use compatible human-annotated constituency trees. If testing the delivered FINAL-D1 projection, use independently transcribed, previously unused Burton–Roberts reference trees with documented conventions or commission independent analyses. Prespecify token alignment, collapsed structure, permissible alternatives, and the treatment of failures. Disable exact textbook lookup. Report labeled precision, recall and F1, full exact/all, and canonical and aligned coverage by stratum. Size the cohort for the desired uncertainty in the smallest claimed stratum and account for sentence clusters from a common source. A narrow independently published reference cohort is sufficient for a narrow claim. Where independent FINAL-D1 answers are unavailable, report the descriptive textbook comparison and limit the independent accuracy claim to the reference formalism actually scored.
2. **H02: one paired blinded feedback comparison.** Use the same frozen sentences and output views for the full system and a legitimate comparable baseline. A grounding-specific causal claim requires freezing the parser, detector, and other components while varying the grounding intervention. If comparing complete systems, interpret the effect at the system level. Before review, define a material error in rule, target, correction, or prose and define what useful, correct feedback requires. Independent qualified reviewers must assess grammar accuracy, correction meaning and completeness, and the accuracy of representative sentence and node explanations. Blind condition and adjudicate disagreements, following the study's expert-review protocol. Report both arms' feedback coverage, no-feedback and inconclusive rates, and incorrect feedback per eligible input, with a secondary rate among cases where feedback was actually shown. Report the paired discordant counts, a paired effect and confidence interval, and an exact McNemar test if independent pairs justify it. Preserve source clusters if using clustered inference. Base sample size on the planned meaningful reduction and expected discordance, and include hard and ambiguous controls. Without a valid comparator and reviewers, retain the current technical outcomes and leave H02 untested. [NIST reference for paired McNemar testing](https://itl.nist.gov/div898/software/dataplot/refman1/auxillar/mcnemar.htm), [published explanation-evaluation rubric](https://aclanthology.org/2024.lrec-main.688/)

These are the additional tests needed for the two hypothesis gaps. Re-running existing regression suites, increasing the size of an exposed textbook sample, or collecting another internal grounding percentage would not address them.
