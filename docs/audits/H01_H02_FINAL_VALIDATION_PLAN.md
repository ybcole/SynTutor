## H01 — Independent constituency reference set

### Source, items and scope

Use the Penn Treebank project’s original bracket annotations from the Open American National Corpus **MASC PropBank Original Files** distribution. Its README identifies the original Penn layer and corresponding text for 88,530 words. The ANC project describes the validated Penn annotations and distributes MASC under CC BY 3.0 US. The selected layer is in `Propbank/Penn_Treebank-orig/`. The larger MASC bracket archive was inspected but is not the reference release for this plan. The chosen original archive SHA-256 is `685b954342a1095fa6c6cab3202b327323554535f1014b204ce3ecab31e94a63`. [Publication and download documentation](https://anc.org/data/masc/downloads/data-download/), [annotation provenance](https://www.anc.org/masc/MASC_Structure.html), [license and attribution](https://anc.org/data/masc/), [original release archive](https://github.com/nancyide/anc-website/releases/download/datasets-2026-09-25/Propbank-original-format.tgz)

**Item register.** Each row of the [180-item reference manifest](technical_evaluation/H01_MASC_PENN_REFERENCE_CANDIDATES.jsonl) records the case ID, exact source sentence, run input, full published bracket tree, complexity stratum and item citation. The citation consists of the source release and archive hash, original document and text member with character offsets, original tree member with one-based tree ordinal and inclusive line range, and both member hashes. The ordinal counts all balanced top-level records in the member, including metadata records preceding a sentence. Character offsets are zero-based, half-open Unicode code-point offsets in the original UTF-8 member. Only whitespace is collapsed for the input sentence and the presentation of the original bracket string. All 180 source spans, cited line ranges and member hashes were checked against the archive without running SynTutor. Manifest SHA-256 `0a048318eeee1721f0612b1722b22cc75964d090587004f22279835aec425470`.

| Gold-derived complexity | Definition | Eligible frame after intake and deduplication | Proposed cohort |
| --- | --- | ---: | ---: |
| C1 | One explicitly marked finite clause | 713 | 60 items, 31 documents |
| C2 | Two explicitly marked finite clauses | 570 | 60 items, 31 documents |
| C3 | Three or more explicitly marked finite clauses | 363 | 60 items, 31 documents |

These categories use the **nearest** `S`, `SINV`, `SQ` or `SBARQ` ancestor of a `VBD`, `VBP`, `VBZ` or `MD` preterminal. Each distinct ancestor counts once. This reference-side proxy covers common overt finite clauses. It can miss imperative, elided or untagged finiteness. C1 can include a nonfinite embedded clause. Record finite nesting depth and lexical length separately. A qualified reader should check a sample of the complexity assignments and resolve scope problems before inference. Use the algorithmic stratum description in reporting unless stronger independent coding is available.

The cohort is drawn across **42 documents** of written English. Intake permits a single sentential root from the four listed categories, at least one marked finite clause, 4–50 reference lexical tokens, complete source punctuation, and a unique original-text location. It excludes newswire/WSJ, Enron and opaque-provenance filenames identified by the intake rule, and excludes spoken data from this written-text target. The 2,112 inspected tree records yielded 1,652 before deduplication. There were 266 out-of-scope roots, 119 nonfinite or out-of-length items, 30 without unique source alignment and 45 outside the punctuation scope. One unbalanced file was quarantined at document intake. Six normalized duplicate records were removed. These are reference intake outcomes recorded before running the parser.

Within each stratum, rank items by SHA-256 of `syntutor-h01-masc-2026-11-22-v1|<tree_member>|<tree_record_1based>` using the literal member string and unpadded ordinal. Retain the first 60 eligible items with at most three per document per stratum. For within-frame duplicates, retain the lowest rank across strata before drawing. If sealing reveals a documented exposure, apply the same ranked replacement rule to the eligible frame and record the change before inference. Underpowered strata may be expanded or reserved for descriptive reporting before any final predictions are released.

### Scoring and the 80% target

1. Submit each frozen original input to the same raw application parse path once under the fixed configuration. Score `parse.parse_string` before FINAL-D1, lookup or grammar evaluation. Require that the application identifies the entire frozen input as the intended single sentence. Score a gold-tokenized Benepar invocation only as an optional diagnostic, separately from the primary raw-input analysis. [Raw parser](../../server/parse_engine.py), [application response mapping](../../server/analysis_api.py)
2. Map overt constituents to a common lexical-character axis after the predeclared normalization. Strip function/coindex suffixes while preserving literal PTB punctuation tags, exclude preterminals, punctuation-only spans, empty nodes and only the artificial outer wrapper. Equal normalized lexical yield is required to compare brackets. Accept different token splits only where both align to the same source character sequence. Keep bracket multiplicities. Match labeled triples `(start, end, category)`; unlabeled scoring drops the category. A full exact match requires identical labeled bracket multisets on aligned output.
3. **Primary estimand is all-attempt labeled micro F1** within each of C1, C2 and C3. Use `2 × sum(matches) / (sum(gold spans) + sum(predicted spans))`. Every frozen item's gold spans contribute. A rejected, missing, timed-out, or unparseable candidate contributes zero matches and zero usable predicted spans. A readable candidate that splits the input or fails yield alignment contributes zero matches and counts its emitted in-scope brackets as unmatched predicted spans. Preserve the cause per case. Exact-match rate uses every frozen input as its denominator. Report precision, recall, unlabeled F1, full exact count, alignment/attempt coverage and failure counts by stratum. Aligned-only F1 is a secondary diagnostic.
4. **80% is a proposed minimum for all-attempt labeled micro F1 in each prespecified complexity stratum.** Approve this operational threshold before running. It is neither an existing result nor the fraction of fully correct trees, grammatical verdicts, explanations, or repairs. For the claim “above 80% across the tested complexity strata,” require every one-sided 95% document-cluster lower bound to exceed 0.80. Report which strata meet the point target and which support the inferential claim. A point estimate of 0.80 alone does not support that claim. Report a balanced aggregate descriptively. This intersection requirement applies to the combined claim about all three strata.
5. Resample documents or linked source families as whole clusters. Use 20,000 paired-across-strata cluster bootstrap draws with a frozen PCG64 seed of 20261122 and use the fifth percentile for the one-sided bound. Assess stability in separate exposed calibration data using cluster-level gold, predicted and match counts. The 60 per stratum are a proposed allocation, with 31 document clusters per stratum before linkage, rather than a power guarantee. Aim for one-sided uncertainty of no more than 10 percentage points per stratum at the planned operating level. If the available cluster counts or precision cannot justify inference, report the estimate and limitations without an H01 pass. Confirm score and failure calculations on development-only cases before unlocking gold.

## H02 — Matched comparison of learner feedback

### Effect and comparator

The causal estimand is the change in **the probability of at least one materially incorrect learner-facing claim or repair per eligible input** when explicit SynTutor grounding is supplied to an otherwise fixed feedback procedure. Both arms handle the same sentence, context, raw spaCy/Benepar output and target node requests, and both can produce all four feedback types. The experimental contrast removes the **matrix/licensing and verified finding bundle** from the control. Raw syntax remains available to both arms as common evidence.

| Shared or varied | Specification |
| --- | --- |
| Common generator | Use the same local structured-output feedback component, model, tokenizer, instruction, allowed actions, context/output budget and deterministic decoding in both arms. A candidate for the isolated research renderer is `Qwen/Qwen2.5-7B-Instruct`. Its exact checkpoint and inference settings still need a reproducible local calibration and freeze. No production model change is proposed. Use the same neutral formatter and one identical rubric for both arms. [Candidate model documentation](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct) |
| Grounding ON | Supply structured production rule evaluations, licensing observations, target and related spans, and their observed/provisional/verified status. Keep conflicting or unsupported evidence explicitly represented. Provide no gold answer, human correction, feedback prose, or suggested wording from the source bundle. |
| Grounding OFF | Use the identical prompt, parsed sentence and tasks with an empty grounding bundle. Allow independent inference and a meaning-preserving correction, a grammar explanation and node explanations. Keep the normal option to qualify uncertainty. Do not substitute acceptability-only, a blank template or a deliberately weakened answer for the active control. |

The shared prompt should ask for a verdict with diagnostic span and reason, a revision or reason for withholding it, a sentence-level explanation, and an explanation for each supplied node span. It should require uncertainty when warranted, no invented authority, and allow a qualified partial correction. Give the requested node ranges to both arms before generating output. Freeze the exact prompt and schema after development-only calibration, and verify that neither arm truncates input or fails to populate all four output channels on cases it can handle.

**Scope of the causal claim.** SynTutor’s current deterministic implementation uses grounded findings directly for correction assembly and content selection. Switching those findings off in the live application would remove much of its feedback. H02's experimental replay isolates the effect of providing explicit grounding to the shared feedback procedure. The grounded replay must be labeled as such. A direct claim about the deployed pipeline requires a fair production-equivalent matched ablation with observable controls, or a separately labeled comparison of production SynTutor with an active baseline that can establish only a whole-system difference. Preserve unedited production API and selected-node packets as implementation records if collecting them later. Do not conflate them with the matched ablation. [Production data dependencies](../../server/analysis_api.py), [explanation evidence assembly](../../server/explanations.py)

### Worksheet and scoring

Use the [blank blinded reviewer worksheet](technical_evaluation/H02_BLINDED_REVIEW_WORKSHEET.csv). The coordinator pre-fills one `packet` row and two `node` rows per packet with the same opaque ID. Reviewer codes are pseudonyms. The target span uses zero-based half-open offsets. Packet rows hold verdict, findings, correction and sentence explanation. Node rows hold requested span, tree status and node explanation. Preserve verbatim rendered feedback. Rate only the applicable cells by row type. Report overall packet-level error and adequacy on the packet row after rating both node rows.

| Dimension | What a reviewer marks |
| --- | --- |
| Grammar verdict and rule | Whether the verdict is warranted, whether the named or described constraint actually applies, and whether the correct target and supporting evidence are identified. Record false rejection, missed error, wrong target, or appropriate uncertainty. |
| Correction | Necessity, grammatical validity, preservation of intended meaning, and whether all determinable required edits were handled. Code completeness as `complete`, `qualified partial`, `unqualified partial`, `withheld`, or `not needed`. Independently defensible alternatives are accepted. |
| Grammar explanation | Truth and applicability of the stated rule and relationship, whether the evidence actually supports it, and whether it accounts for the correction and any uncertainty. |
| Node explanations | For each requested node, verify the span, category/function, relationship and its evidence. Record missing/provisional views and the correctness of any qualifying language. |
| Consistency across outputs | Check that the verdict, diagnosed span, repair, tree status and explanations agree where they refer to the same claim. Independently check truth before granting correctness. |

For grade fields use **4** fully correct and adequately supported, **3** correct with a minor omission, **2** materially incomplete or mixed, **1** materially incorrect or misleading, **U** unresolved under the available reference/context, **M** needed output missing, and **NA** genuinely inapplicable. For flags use **1**, **0**, or **U**. Record reference status as `published match`, `independently adjudicated`, `partially referenced`, or `unresolved`. Record the affected claim and its linguistic basis with an exact citation or reason. Use *The Cambridge Grammar of the English Language* for compatible grammatical judgments and the third-edition Burton–Roberts conventions for the displayed structural claims. Keep a published general rule distinct from a reviewer's judgment about its applicability in context. Grade 2 alone does not decide the material-error flag. Examples of a material error include condemning a grammatical control, teaching a false relationship, asserting a definite analysis where only an ambiguous one is available, offering a meaning-changing repair, or calling a partial repair complete. A qualified abstention is not itself an incorrect assertion. A required omission lowers adequacy. The independent worksheet is for linguistic validity. Separately check automated source-offset/ID integrity and the agreement between displayed claims and their supplied evidence for technical faithfulness. [Cambridge grammar](https://www.cambridge.org/core/books/cambridge-grammar-of-the-english-language/A78402ABF5176AD283494180BCA2046F)

### Analysis and minimum decision rules

- Record material error in each arm as 1 if there is at least one adjudicated material error across the packet and its two node requests, and 0 if no such error was displayed. The primary paired effect is the **OFF material-error rate minus the ON material-error rate**, over all eligible inputs. Report absolute rates, the two discordant counts and a paired effect interval. A missing response or bare abstention contributes 0 to error occurrence and 0 to adequate feedback. Report no-feedback, partial, timeout, inconclusive and feedback-shown rates in each arm. Also report incorrect-feedback rates among packets with substantive output. For unresolved reviewer flags, report counts and best/worst paired bounds. An inference for the full cohort requires the reduction decision to survive the adverse assignment.
- Adequacy requires correct and usable feedback for every applicable field, with appropriate uncertainty when the source does not establish a uniquely valid reading. Require the one-sided paired lower bound for the ON minus OFF adequate-feedback rate to exceed **−5 percentage points**, a proposed noninferiority margin to approve before the run. This prevents apparent safety gains obtained by withholding usable feedback. H02 needs a positive one-sided paired lower bound for error reduction and the adequacy criterion. The H01 80% threshold has no role in testing reduction.
- Use an exact one-sided McNemar test at `α = 0.05` with independent sentence pairs. If authors, essays or prompts remain linked, preserve their clusters in paired interval and test calculations. Report component measures with their own denominators. These include detection precision/recall/F1 and verdict coverage, ERRANT 3.0.0 edit precision/recall/F0.5 on original M2, correction validity among offered edits, completeness among cases needing correction, and grammar prose accuracy both on all applicable packets and among displayed prose. Use both frozen requests per case for node prose accuracy and state span-mapping and node availability counts separately. Use adjudicated flags for material errors and keep node observations linked to sentences in inference. [Paired statistical test](https://itl.nist.gov/div898/software/dataplot/refman1/auxillar/mcnemar.htm), [ERRANT](https://aclanthology.org/P17-1074/)
- Set H02 sample size from an independent calibration of discordance and the adequacy margin before final selection. As a design illustration only, under independent discordant probabilities 0.15 favoring ON and 0.05 favoring OFF, 134 pairs give about 80% power for the exact one-sided 5% reduction test. The adequacy guardrail, source linkage and unrateable cases can require a larger sample. With fewer independent units or unavailable reviewers, label the study exploratory and retain H02 as untested. Power is a planning quantity distinct from the H01 accuracy threshold.

## Final run record

Before inference, register the hypothesis scope, both manifests or reference-source gates, input and exclusion hashes, annotation/sampling policies, thresholds, prompt and worksheet checksum, runtime and dry-run checks, and identity of the independent custodian. Lock the design before outputs are viewed. After an authorized run, preserve per-attempt outputs, failures, source citations, scorer files, review records and their hashes separately from earlier runs. A missing reference prevents a claim of accuracy for that field. Model output can be compared to published or human answers and cannot create its own independent answer key. This protocol measures structural agreement and feedback quality under stated conditions. Educational effectiveness requires separate learner-outcome evidence.
