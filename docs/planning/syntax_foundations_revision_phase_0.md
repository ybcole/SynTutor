## Fresh start and verified XP design

- Add a new versioned catalog and guarded save/submit path for revised Foundations. Keep the old answer keys and immutable migrations. Store section events, first diagnostic result, attempt records and best verified score in identity-scoped state. The server derives identity from the verified JWT, validates stage and answer IDs and computes score and XP. Section visits are progress evidence, not proof that someone read the page. Use existing authored trees and reviewed answers as the grading source.
- Under the existing per-user transaction lock, deduplicate by attempt ID and reject reuse with a different payload. For `n` equally weighted questions, the cumulative eligible amount is `floor(15 × best_correct / n)`. Record only the positive difference, with immutable award events. Latest and best scores remain distinct. A first 0/5 completes the chapter after required stages and earns 0 XP. If the learner submits before finishing required sections, save the attempt and verify completion when the remaining sections are recorded. A local preview can show a provisional score, but account awards need server confirmation. Preserve queued requests across failed sync and retries.

Retire obsolete `br-01`–`br-11` award versions from active totals when each replacement goes live. Block obsolete award writes at that cutover so older clients cannot regain retired XP. Reconcile `player_stats` under the same lock and preserve quiz XP, Chapter 12 XP, account records and unrelated fields. Cross-check the ledger, `get_my_progression` and leaderboard windows against fixtures that include both old lesson and unrelated XP. M8 achievement predicates use completion and content version. ### Chapter 1 pilot preview

- Introduce a setting and show the nested groups in “Mara waited [beside [the station clock]].” The phrase *the station clock* names a landmark. The larger group places Mara's wait relative to that landmark.
- Ask the learner to compare “Mara waited there” with the original, then use “Where did Mara wait?” to locate the same span. Ask what would be lost if a tree joined each word directly to the sentence. Trace the inner and outer nodes on an authored tree.
- Transfer to “The guard moved the box with the handle.” Let the learner test two groupings by deciding whether the handle identifies the box or was used to move it. Use one explicitly stated context per reading, followed by a recap of evidence and immediate grouping. Verify the authored trees before building this exercise.
- Use five opening and five distinct closing items. Map the closing items to the inner span, outer span, one replacement, one direct-child relation and one reading-dependent attachment. Reserve roughly 2 minutes for each check, 2 minutes for the concept and worked tree, 2 minutes for transfer and 1 minute for the recap. This is a proposed nine-minute path pending timing.
