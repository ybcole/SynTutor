# Milestone 05 implementation brief

This previously missing workstream brief is restored from the authoritative execution plan's unchanged Milestone 05 criteria and the master plan's Quizzes section. It does not expand the approved scope.

Create independent five-question assessments using original, reviewed questions mapped to lesson outcomes, printed-page sources and convention profiles. Support topic/chapter, cumulative, diagnostic and challenge blueprints; select equivalent variants and shuffle question/option order. Keep lesson practice/completion separate.

Review a representative question/scoring sample before expanding the bank. The standing owner authorization covers implementation and the AI verification pass; record its identity without claiming human instructor approval. Only the limited source-reviewed M4 outcomes are eligible. Unreviewed/unimplemented Cambridge constraints cannot grade grammaticality.

Persist versioned attempts and immutable submissions, best/last scores and answer history. Award max(0, 10 - 2 × incorrect), only as an improvement over the prior best reward for that assessment version. Repeated scores award zero. Use the shared source-based explanation engine after submission; offer targeted, rotated reinforcement without mastery claims.

Verify every score, repeat/retry behavior, randomization, persistence, account isolation, trusted SQL rewards, source/schema contracts, browser/mobile rendering and packaging. Prepare additive migrations; do not imply live deployment. Retain old published versions and legacy data.
