# Historical parser lessons

`tree-quiz.js` is the original M4-predecessor module, retained for audit/rollback.
It is not imported by the app and is outside `web/`, so its unsupported prose,
parser-derived lesson targets and old reward path are not published. The audit
and replacement map is `docs/curriculum/legacy-lesson-audit.md`. Relative imports
in this historical source are not maintained as an executable app.
